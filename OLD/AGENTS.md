# OLD/AGENTS.md

Reference cabinet for our own code that's no longer in active use but might be useful to look back on later. Move things here instead of deleting them or leaving them cluttering the main tree.

The repo already has a lowercase `old/` directory (`it0_intermediate_results_and_code`, `it1_defer_mitsuba_testings`, `it2_reverse_analysis`, `it3_trellis_prior`) serving informally as this same kind of cabinet. It has not been consolidated into `./OLD/` yet — treat `old/` as a pre-existing precursor to this convention rather than migrating it automatically.
